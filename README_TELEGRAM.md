# Neon Arena — Telegram Mini App + Bot

Telegram-версия **Neon Arena v1.5.11**, собранная как Main Mini App внутри Telegram-бота.

## Что уже реализовано

- Исходный геймплей Neon Arena v1.5.11, включая временные усиления.
- Запуск игры из Telegram-бота через Web App кнопку.
- Автоматическая идентификация игрока через Telegram Mini Apps `initData`.
- Серверная проверка подписи `initData` (HMAC), а не доверие данным из браузера.
- Серверный рейтинг игроков в SQLite.
- Сохранение прогресса.
- Telegram Stars (`XTR`) для покупки Neo Crystals.
- Магазин мифической косметики за Neo Crystals.
- Серверная защита платной валюты и платной косметики от простой подмены localStorage.
- Ежедневная награда за Top-10 рейтинга.
- Команды `/start`, `/play`, `/leaderboard`, `/terms`, `/support`, `/paysupport`.
- Long polling для простого запуска и webhook-режим для production.
- Dockerfile.
- DEV_MODE для запуска игры в обычном браузере без Telegram.

> В Telegram-версии намеренно нет сторонних rewarded-video блоков. Telegram Stars используются для цифровых покупок, а рекламная монетизация Telegram — отдельный механизм платформы.

## Архитектура

```text
Telegram user
    │
    ├── Telegram Bot ──────────────┐
    │                              │
    └── Main Mini App (HTML5)      │
            │                      │
            └── HTTPS API ─────────┤
                                   ▼
                             Node.js server
                                   │
                                   └── SQLite
                                       ├── users
                                       ├── purchases
                                       └── payment_events
```

Frontend находится в `public/`. Bot API, платежи, рейтинг и сохранения находятся в `server.js`.

## Требования

- Node.js 22.5+.
- Telegram-бот, созданный через `@BotFather`.
- Публичный HTTPS-домен для production Mini App.
- Постоянный диск/volume для каталога `data/` в production.

## Быстрый локальный запуск

1. Скопируйте настройки:

```bash
cp .env.example .env
```

2. Для локального теста без Telegram установите:

```env
DEV_MODE=true
BOT_TOKEN=
BASE_URL=http://localhost:3000
WEBAPP_URL=http://localhost:3000
```

3. Запустите:

```bash
npm start
```

4. Откройте `http://localhost:3000`.

DEV_MODE предназначен только для разработки. Платежи Stars и настоящая Telegram-авторизация должны проверяться внутри Telegram.

## Настройка Telegram-бота

### 1. Создание бота

Откройте `@BotFather`, выполните `/newbot`, задайте название и username, затем получите Bot Token.

Никому не отправляйте этот токен и никогда не помещайте его в `public/`, JavaScript клиента или Git.

### 2. Размещение проекта

Разместите проект на сервере с HTTPS. Например:

```env
BOT_TOKEN=123456789:YOUR_REAL_TOKEN
BASE_URL=https://game.example.com
WEBAPP_URL=https://game.example.com
PORT=3000
HOST=0.0.0.0
DATA_DIR=./data
SUPPORT_USERNAME=your_support_username
DEV_MODE=false
```

`server.js` автоматически читает `.env` из корня проекта.

### 3. Подключение Main Mini App

В `@BotFather` откройте вашего бота и настройте Mini App / Main Mini App. В качестве URL укажите тот же HTTPS URL, который указан в `WEBAPP_URL`.

После этого пользователи смогут запускать Neon Arena непосредственно из профиля бота и по кнопке **Играть**.

### 4. Команды

Сервер при запуске пытается настроить команды автоматически. Основные команды:

- `/start` — стартовое сообщение и кнопка запуска.
- `/play` — открыть игру.
- `/leaderboard` — показать Top-10.
- `/terms` — условия цифровых покупок.
- `/support` — поддержка.
- `/paysupport` — поддержка по платежам.

Обязательно заполните `SUPPORT_USERNAME` перед реальными продажами.

## Telegram Stars

В `server.js` настроены стартовые тестовые цены:

| SKU | Награда | Цена |
|---|---:|---:|
| `neo_crystals_250` | 250 Neo Crystals | 50 Stars |
| `neo_crystals_500` | 500 Neo Crystals | 90 Stars |
| `neo_crystals_1000` | 1000 Neo Crystals | 160 Stars |

Это не «официально оптимальные» цены — это стартовая сетка для тестирования конверсии. Меняются в объекте `PRODUCTS` в `server.js`.

Платежный поток уже реализован:

```text
Mini App → /api/invoice → createInvoiceLink
         → Telegram invoice (XTR)
         → pre_checkout_query
         → successful_payment
         → telegram_payment_charge_id сохраняется в БД
         → сервер начисляет Neo Crystals
```

Начисление происходит только после `successful_payment`. Клиент не может сам подтвердить покупку.

## Монетизация — рекомендуемая модель

### 1. Neo Crystals за Telegram Stars — уже реализовано

Основной источник выручки. Neo Crystals лучше тратить исключительно на косметику: скины, снаряды, следы, рамки профиля, анимации победы.

Не продавайте прямой урон, HP, скорость или рейтинговые преимущества — иначе платящие игроки будут влиять на честность таблицы лидеров.

### 2. Сезонный Neon Pass — следующий этап

Хорошая следующая функция: 30-дневный сезон с косметическими наградами, миссиями, рамкой профиля и уникальным визуальным эффектом. Его можно продавать за Stars либо сделать Star-подписку после того, как появится стабильная аудитория.

### 3. Лимитированные наборы

Например: `Phoenix Pack`, `Void Pack`, `Founder Pack`. Лучше продавать редкую косметику и визуальные эффекты, а не силу персонажа.

### 4. Telegram Affiliate Program

После появления хорошей конверсии можно включить официальную партнёрскую программу Mini App. Блогеры и владельцы каналов получают персональные ссылки и процент Stars с покупок привлечённых пользователей. Для старта разумно тестировать комиссию около 15–20%, но итоговая ставка должна зависеть от вашей маржи и LTV.

### 5. Рекламная монетизация Telegram

Telegram поддерживает распределение рекламной выручки для ботов/каналов. Это отдельный механизм платформы, а не «rewarded video API» внутри игрового canvas. Поэтому текущая сборка не подменяет его сторонней рекламой.

## Что лучше продавать

Хорошо подходят:

- уникальные скины;
- пули/трейлы/эффекты смерти;
- рамки и значки профиля;
- сезонный пропуск;
- дополнительные cosmetic loadout slots;
- эмоции/анимации победы;
- Founder Pack;
- временные визуальные события.

Для рейтингового режима не рекомендуется продавать урон, HP, скорость, щит, дополнительные жизни или платный revive. Если позже понадобится платный revive — лучше выделить его в отдельный **Unranked** режим.

## Защита от читов

Уже защищено сервером:

- баланс Neo Crystals;
- владение мифической косметикой;
- покупки Stars;
- одноразовое начисление покупки;
- ежедневная Top-10 награда;
- лучший результат и таблица лидеров — серверные.

Есть базовая проверка правдоподобности результата, однако сама симуляция боя пока выполняется на клиенте. Для крупного соревновательного проекта следующим этапом должен быть более строгий anti-cheat: подписанные run-сессии, серверная проверка событий/таймингов или replay verification. Клиентский JavaScript нельзя считать полностью доверенным.

## Важная информация о платежах

Для цифровых товаров внутри Telegram используйте Telegram Stars (`XTR`). Не добавляйте внутрь Mini App альтернативную кнопку оплаты цифровой валюты картой, криптовалютой или сторонним процессингом.

Telegram требует поддержку по платежным вопросам. В проекте есть `/paysupport`, а `telegram_payment_charge_id` каждого успешного платежа сохраняется для возможного возврата через Bot API `refundStarPayment`.

Перед production-запуском рекомендуется:

- включить 2FA на аккаунте владельца бота;
- заполнить `/terms` и контакты поддержки;
- протестировать платежи в тестовом окружении Telegram;
- настроить резервное копирование SQLite;
- ограничить доступ к серверу и токену;
- подключить мониторинг ошибок;
- после роста нагрузки перейти с SQLite на PostgreSQL.

## Long polling и webhook

По умолчанию, если `WEBHOOK_URL` пустой, бот использует long polling. Это удобно для MVP.

Для production можно настроить:

```env
WEBHOOK_URL=https://game.example.com/telegram/webhook
WEBHOOK_SECRET=LONG_RANDOM_SECRET
```

Не используйте случайный ephemeral-файловый диск: база должна сохраняться между рестартами.

## Docker

```bash
docker build -t neon-arena-telegram .
docker run --rm \
  -p 3000:3000 \
  --env-file .env \
  -v neon_arena_data:/app/data \
  neon-arena-telegram
```

Снаружи контейнера нужен HTTPS reverse proxy либо платформа, которая автоматически выдаёт HTTPS URL.
